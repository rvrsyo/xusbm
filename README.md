# Faculty photos

Drop headshot images here, named to match the "photo" field in faculty.json,
e.g. rrussell.jpg, rgevero.jpg.

Recommended: square crop, at least 400x400px, JPG or PNG, under 300KB each
(resize before uploading so the site loads fast on mobile data).

If a person's "photo" field is left empty ("") or the file is missing,
the site automatically shows a navy circle with their initials instead —
so it's safe to publish before every photo is collected.
